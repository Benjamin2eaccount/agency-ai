# Environment Variables

All `process.env` variables read by the application, generated by grepping the codebase.

## Required in Production

| Variable | Purpose | Behavior if missing |
|----------|---------|-------------------|
| `JWT_SECRET` | Signs and verifies JWT auth tokens | **Refuses to start** in production (`process.exit(1)`). Falls back to insecure dev-only default in development. |
| `DATABASE_URL` | PostgreSQL connection string (Railway) | Falls back to SQLite (`data/database.sqlite`). PG features (cron_logs table, workspace_keys) disabled. |
| `CLAUDE_API_KEY` | Anthropic Claude API key for AI agents | AI calls fail with error. Health check reports `claude_api: missing`. Also accepted as `ANTHROPIC_API_KEY`. |

## Authentication

| Variable | Purpose | Behavior if missing |
|----------|---------|-------------------|
| `ADMIN_USERNAME` | Override default admin login username | Defaults to `admin` |
| `ADMIN_PASSWORD` | Override default admin login password (bcrypt hash or plaintext) | Defaults to `agency2024` |
| `SETUP_TOKEN` | Token required for initial setup routes (`/setup/*`) | Setup routes return 401 in production. Not required in development. |

## Email / IMAP

| Variable | Purpose | Behavior if missing |
|----------|---------|-------------------|
| `RESEND_API_KEY` | Resend.com API key for transactional email | Email sending disabled. Cold outreach and notifications won't send. |
| `RESEND_FROM_ADDRESS` | Sender address for Resend emails | Falls back to settings.json `emailFrom` or default. |
| `GMAIL_ADDRESS` | Gmail address for IMAP reply checking | IMAP reply detection disabled. |
| `GMAIL_USER` | Gmail username (alias for GMAIL_ADDRESS in some contexts) | Falls back to GMAIL_ADDRESS. |
| `GMAIL_APP_PASSWORD` | Gmail app password for IMAP | IMAP reply detection disabled. |
| `IMAP_PASSWORD` | Alternative IMAP password variable | Falls back to GMAIL_APP_PASSWORD. |

## Server

| Variable | Purpose | Behavior if missing |
|----------|---------|-------------------|
| `PORT` | HTTP server listen port | Defaults to `3000` |
| `NODE_ENV` | Environment mode (`production`, `test`, `development`) | Defaults to development behavior. `test` disables cron jobs and some logging. |
| `RAILWAY_ENVIRONMENT` | Railway deployment indicator | Used alongside `DATABASE_URL` to detect production mode. |
| `BASE_URL` | Public URL of the app (used in emails, portal links) | Defaults to `https://www.agencyai.info` |

## Notes

- `CLAUDE_API_KEY` and `ANTHROPIC_API_KEY` are interchangeable — both are checked.
- In production (Railway), `DATABASE_URL` provides PostgreSQL. Locally, SQLite is used automatically.
- Email configuration can also be set via the Settings UI (stored in settings.json), but env vars take precedence for IMAP credentials.
