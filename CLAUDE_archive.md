## What we are building

- Finds 15 businesses daily with AI
- Researches each one with 6 agents
- Shows me an approve/disapprove inbox
- Sends emails via Gmail automatically
- Tracks follow-ups and replies
- Works on iPhone as PWA
- Has login security

## Deployment instructions (Railway.app)
1. Push to GitHub (data/ and .env are gitignored — safe)
2. Go to railway.app → New Project → Deploy from GitHub
3. Add environment variables:
   - CLAUDE_API_KEY = your Anthropic API key
   - JWT_SECRET = any long random string
4. Railway auto-detects Node.js and runs `npm start`
5. data/ auto-creates on first boot with default settings
6. Open the Railway URL → login with admin / agency2024
7. Go to Settings → change password immediately
